# 팀 프로젝트 - CAKE QUAKE(SPA)

* 프로젝트 기간: 2025년 05월 08일 ~ 2025년 07월 10일
* 개발 인원: 총 5명(전원 풀스택 개발)
    * 내 역할: 로그인, 회원 가입, JWT기능
* 프로젝트 설명: AI를 활용한 레터링케이크 예약 및 발주 시스템
    * React 기반의 웹 애플리케이션 (사용자 화면)

---
### 개발 환경

* **운영체제**: Windows11
* **개발 언어**: JavaScript
* **Frontend**: React, React Router v7, Tailwind CSS, HTML5, CSS3
* **개발 도구**: VSCode, Vite
* **라이브러리**: Zustand, React Query, Axios

---
### 주요 구현 기능

* 시스템 주요 기능 요약
    * AI 기반 디자인 추천, 통합 예약 시스템, 온도 지수,  발주 시스템,
      JWT 기반 인증 및 권한 분리 로그인 시스템 (Spring Security 적용), 카카오톡 소셜 로그인 기능


* 구현 방식
    - React Router의 Lazy / Suspense를 활용한 코드 스플리팅
    - 페이지 라우팅 전용 컴포넌트(`/pages`) 구성
    - 화면 단위 UI 컴포넌트(`/components`) 분리
    - 동일 로직에 대한 공통 컴포넌트를 제작해서 재사용
    - '처리 결과'를 위한 모달 컴포넌트 구성


- 맡은 기능들

### 1. 로그인 및 JWT 인증


- **JWT 기반 인증/인가 구현**
    - axios 인터셉터로 토큰 자동 포함 및 만료 시 재발급 처리
    - refreshToken 만료 시 로그인 페이지로 리다이렉트

- **전역 로그인 상태 관리**
    - React Context API를 활용해 사용자 인증 상태를 전역에서 공유
    - 로그아웃 시 상태 초기화 및 서버 쿠키 삭제

- **권한 기반 라우팅**
    - 사용자 정보(`role`, `shopId` 등)에 따라 로그인 후 각 역할의 첫 화면으로 자동 리다이렉트
    - `RequireAuth` 컴포넌트로 접근 권한 제어


###	2. 카카오 소셜 로그인
- 기존 유저 → 바로 토큰 발급 & 로그인 완료
- 신규 유저 → 소셜 회원가입 페이지로 이동
- 신규 가입 화면에서 카카오 계정 정보(이메일, 닉네임)를 바로 표시하기 위해 **zustand로 상태 관리** 적용

###	3. 회원 가입
- 모달 창 기반 인증 UI 제공
- 판매자 회원 가입
    - **다음 주소 API** 연동으로 매장 주소 검색 지원
    - 매장 이미지 및 인증 파일 업로드 시, 정적 파일은 **Nginx**를 통해 별도 관리

###	4. 매장 승인 관리 기능
- **무한 스크롤 목록**
    - React Query `useInfiniteQuery`로 페이지네이션 + 스크롤 시 자동 데이터 로딩 구현

- **승인/보류/거절 처리**
    - `useMutation`으로 상태 변경 API 호출 및 결과 반영
    - 처리 성공 시 알림 모달 표시 후 목록 자동 갱신


### 사용자 중심의 입력 흐름 설계

직접 서비스를 사용하면서 불편했던 점들을 개선하고, 사용자 경험(UX)을 높이기 위해 다음과 같은 작업을 진행했습니다.

- **입력 오류 시 자동 포커스 이동**
    - 입력 항목이 많은 **판매자 회원가입** 화면에서 편리성 강화
    - `useRef`를 활용해 유효하지 않은 입력값이 있으면 해당 input으로 자동 이동

- **페이지 이동 시 스크롤 위치 초기화**
    - 무한 스크롤 구조에서 상세 페이지 이동 후에도 스크롤이 남아있는 문제를 개선
    - 새 페이지 진입 시 스크롤을 맨 위로 초기화하여 자연스러운 탐색 제공

- **세부 UX 개선**
    - 비밀번호와 확인 불일치 시 실시간 오류 표시
    - 전화번호 인증 완료/사업자 정보 조회 완료 시 버튼 색상 변경 및 클릭 방지 처리
